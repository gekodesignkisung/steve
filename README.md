# steve

**만져보기 전엔 모른다** — 스티브 잡스가 시도했을 다섯 가지 조작 은유를, 읽는 글이 아니라 만지는 데모로 만든 페이지.

빌드 도구 없음. `index.html`을 브라우저로 바로 열면 동작합니다.

```
steve/
├─ index.html
├─ css/styles.css
└─ js/app.js
```

## 다섯 표본

| | 은유 | 조작 | 무엇을 증명하나 |
|---|---|---|---|
| FIG. 01 | 휠 | 원 그리기 | 빠르게 돌릴수록 한 칸 임계각이 14° → 3.2°로 줄어드는 가속 모델 |
| FIG. 02 | 바운스 | 플릭 | 데이터·기능이 완전히 같은 두 스크롤러. A는 경계에서 즉사, B는 관성 + 스프링 복귀 |
| FIG. 03 | 스케일 | 수직 드래그 | 텍스트 입력 0자로 설명 상세도 5단계 조절 |
| FIG. 04 | 명사 후 동사 | 선택 → 동사 | 대상을 고르면 가능한 동사만 그 위에. 실제 CSS 필터·SVG 레이어로 적용 |
| FIG. 05 | 이미 끝난 것 | 한 번의 탭 | 같은 예약 과제를 대화 4왕복 vs 좌석표 1탭. 입력 횟수·대기 시간 실측 |

## 원칙

**가짜 AI 응답을 넣지 않는다.** 모든 결과는 사전에 작성된 텍스트이거나 실제 물리·CSS 연산입니다.
FIG. 05의 대화만 사전 스크립트이며, 화면에 시뮬레이션임을 명시합니다.

FIG. 02의 A판은 "나쁜 예"로 따로 만든 것이 아니라 **관성 계산만 빼고 나머지는 동일한 코드**입니다.
그 한 줄 차이가 손끝에 어떻게 다르게 오는지가 이 페이지 전체의 논거입니다.

## 만듦새

- 라이트/다크 테마 토큰, 한글 `word-break: keep-all` 줄바꿈
- 휠·손잡이 키보드 조작, `prefers-reduced-motion` 대응
- 외부 요청 없음 (폰트·이미지·스크립트 CDN 미사용)
