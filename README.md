# steve

**스티브 잡스가 만들었던, 그리고 만들었을 인터페이스 표본들**

읽는 글이 아니라 만지는 표본으로 만든 페이지. 열 개의 조작 은유가 전부 실제로 동작합니다.

→ [gekodesignkisung.github.io/steve](https://gekodesignkisung.github.io/steve/)

빌드 도구가 없습니다. `index.html`을 브라우저로 바로 열면 동작하고, 개발 서버가 필요하면 `node server.js` (기본 4050 포트).

```
steve/
├─ index.html
├─ css/styles.css
├─ js/app.js
├─ server.js                        의존성 없는 정적 서버
├─ fonts/PretendardVariable.woff2
├─ image.png                        시작 판 초상
└─ ziggy-walk-the-walk.mp3          FIG.01 재생 음원
```

| | 은유 | 조작 | 무엇을 증명하나 |
|---|---|---|---|

| 02 | 바운스 | 플릭 | 데이터·기능이 완전히 같은 두 목록. A는 경계에서 즉사, B는 관성 + 스프링 복귀 |
| 03 | 끌어다 놓기 | 집어서 놓기 | 1984년이 없앤 것은 `mv` 명령어였다. 안 쳐도 되는 명령어를 옆에 표시 |
| 04 | 밀어서 열기 | 수평 드래그 | 92%까지 밀어야 열리고, 중간에 놓으면 아무 일 없이 되돌아온다 |
| 05 | 바뀌는 자판 | 맥락 의존 자판 | 메일 칸에서 스페이스가 사라지고 `@`·`.com`이 생긴다. 카드 칸은 숫자판 |
| 06 | 명사 후 동사 | 선택 → 동사 | 대상을 고르면 그 대상이 할 수 있는 일만 나타난다 (Xerox Star 1981) |

## 원칙

**가짜 AI 응답을 넣지 않는다.** 모든 결과는 사전에 작성된 텍스트이거나 실제 물리·CSS 연산입니다. FIG.09의 확신 등급과 FIG.10의 버전들도 전부 미리 써둔 것이고, 모델을 부르지 않습니다.

**외부 요청이 없다.** 폰트·이미지·음원 전부 저장소 안에 있습니다. CDN을 한 곳도 부르지 않습니다. 밖으로 나가는 링크는 하단 서명 하나뿐이고, 그것도 눌러야 이동합니다.

**주장 대신 실측.** 임계각, 경계초과 픽셀, 자판 교체 횟수, 잃어버린 버전 수 — 계측기의 값은 전부 그 순간 계산된 것입니다.

**되돌릴 수 있다.** 모든 표본은 몇 번이고 다시 시도할 수 있습니다. 실패에 대가가 없어야 손이 움직입니다.

## 짚어둘 것

FIG.02의 A판은 나쁜 예로 따로 만든 것이 아니라 **관성 계산만 빼고 나머지는 동일한 코드**입니다. 그 한 줄 차이가 손끝에 어떻게 다르게 오는지가 이 페이지 전체의 논거입니다.

FIG.06은 원래 미래 칸에 있었으나 과거로 옮겼습니다. 이미 모든 편집기에 있는 보편 패턴이고, 출처도 잡스가 아니라 제록스 PARC의 래리 테슬러입니다.

바운스 특허(US 7,469,381)의 출원인은 애플이며 **잡스는 발명자가 아닙니다.** 초안에 잘못 적었다가 바로잡았습니다.

- 라이트/다크 테마 토큰, 한글 `word-break: keep-all` 줄바꿈

- 표본판 높이는 JS가 휠 판을 기준으로 통일 — 탭을 눌러도 상자가 덜컹거리지 않음
